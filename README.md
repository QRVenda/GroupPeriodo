# GroupPeriodo

Componente TGroupPeriodo para configurar grupos de datas.  
Útil para filtrar dados em tela e para relatórios.

---

## ⚙️ Configuração

Adicione o caminho do componente no **Library Path** do Delphi.

### Caminho a adicionar:
GroupPeriodo\src

### Como configurar no Delphi:
Tools → Options → Language → Delphi → Library → Library Path
